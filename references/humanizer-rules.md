# 去痕规则库

移植自 `chi111i/BypassAIGC`（CC BY-NC-SA 4.0）的 humanizer 规则，展开为可执行条目。
每条都给出「为什么像 AI」和「怎么改」。**改写时按此表逐条比对，不是通读一遍凭感觉改。**

## 总纲

> 改写，不删信息。原文有的内容改完还要在；原文没有的日期、数字、来源、因果、评价，不补。

这一条压过后面所有细则。常见翻车不是"没改干净"，而是"改得太起劲"——把事实改没了，或补了原文没有的判断。补事实是硬错误，比残留套话严重。

改完的句子要有**主语、动作、结果**三件东西。句长要有长有短。抽象评价只改写成原文已经提供的具体说法，没有就删，不编。

---

## 一、拔高类（把普通事说成里程碑）

| 禁用 | 为什么像 AI | 改法 |
|---|---|---|
| 具有重要意义 / 具有深远影响 | 没有说出"对谁、在什么方面、有多大" | 删掉，或写出具体影响："使训练时间从 6 h 降到 2 h" |
| 开启新篇章 / 开启新时代 | 新闻通稿语 | 删 |
| 推动变革 / 推动行业革新 | 空动作 | 写出具体改变了什么流程 |
| 关键时刻 / 关键节点 | 伪重要性 | 删，或给出判断依据 |
| 奠定基础 / 奠定了坚实基础 | 学术里偶尔合法（"为…奠定了理论基础"），但 AI 会滥用 | 只在真有后续工作时保留，否则删 |
| 具有广阔的应用前景 | 论文结尾万能句 | 写出已经验证的具体场景，或删 |

**示例**
- 原文：该方法的提出对图像识别领域具有重要意义。
- 改写：该方法在 CIFAR-10 上把错误率降低了 3.1 个百分点。

（如果原文没有这个数字，就只写"该方法在 CIFAR-10 上降低了错误率"，不许编 3.1。）

---

## 二、热度空话（假装有共识）

禁用：广受关注、引发热议、引发广泛关注、业内好评、备受瞩目。

改法：说出谁在关注、关注什么。写不出就删。

- 原文：近年来，深度学习在图像识别领域广受关注。
- 改写：深度学习已成为图像识别的主流方法。

---

## 三、假分析（有动词，没内容）

这是中文 AI 文本最典型的病。句式是"通过 A 实现 B"、"依托 A 推动 B"、"围绕 A 展开 B"——语法完整，信息为零。

| 禁用句式 | 问题 |
|---|---|
| 通过…实现… | A 和 B 之间的机制没说 |
| 依托…推动… | 同上 |
| 围绕…展开… | 只是把标题重说一遍 |
| 以…为核心 / 为抓手 / 为导向 | 黑话化 |

改法：**把机制写出来，写不出就把句子降级成陈述。**

- 原文：通过引入注意力机制，实现了识别精度的提升。
- 改写：模型在卷积层后加入通道注意力，对每个通道的特征响应重新加权，识别精度随之提高。

- 原文：本文围绕图像识别的准确率问题展开研究。
- 改写：本文处理的是小样本条件下的识别准确率问题。

---

## 四、宣传词（广告语混进正文）

禁用：领先、卓越、极致、革命性、颠覆性、全方位、赋能、护航、助力腾飞。

改法：换成可验证的描述，或直接删。"性能领先"→"比 baseline 高 2.4 个点"；"全方位覆盖"→列出覆盖了哪几项。

---

## 五、假权威（无出处的归因）

禁用：有人认为、业内普遍认为、专家指出、相关人士表示、研究表明（后面没有引用编号）。

改法：要么补上引用 `[12]`，要么把判断收回成作者自己的判断（"本文认为"），要么删。

> ⚠️ 这一条和"不补事实"配合看：**不许为了让句子完整而编一个引用编号。** 原文没有引用就删掉归因，不要造。

---

## 六、套话收尾

禁用：机遇与挑战并存、未来可期、前景值得期待、具有广阔的发展前景、相信在不久的将来。

改法：结尾要么给结论，要么给下一步的具体工作。"未来将研究 X" 比 "未来可期" 好，因为它有内容。

---

## 七、互联网黑话（最刺眼的一类）

禁用：赋能、生态、闭环、抓手、底层逻辑、价值沉淀、长期主义、深度融合、全链路、颗粒度、场景化、范式、跃迁。

这些词在技术文档里出现，读者立刻判定"这是 AI 或 PPT 写的"。学术论文里一律替换：

| 黑话 | 替换 |
|---|---|
| 赋能 | 使…能够 / 支持 |
| 生态 | 一组工具 / 相关项目 |
| 闭环 | 完整流程 / 从…到…的回路 |
| 抓手 | 切入点 / 具体措施 |
| 底层逻辑 | 原理 / 原因 |
| 全链路 | 从头到尾 / 整个流程 |
| 颗粒度 | 细化程度 |
| 场景化 | 针对具体场景的 |
| 范式跃迁 | 方法上的根本改变 |

---

## 八、系词伪装（该用"是"的时候不用）

禁用：可视为、可以视为、呈现出、体现了、彰显了、标志着、折射出、构成了…的重要一环。

AI 模型倾向于回避最简单的"是"。**能用"是"就用"是"。**

- 原文：该结果体现了模型具有较强的鲁棒性。
- 改写：这个结果说明模型比较稳定。

- 原文：这一变化标志着训练策略的转折。
- 改写：训练策略从这一步开始改变。

---

## 九、否定排比与空并列

| 禁用 | 问题 |
|---|---|
| 不是…而是… | 用一次可以，连着用就是模板 |
| 不只是…更是… | 同上 |
| 不仅是…还是… | 同上 |
| 更快、更稳、更智能（三连） | 三个形容词并列，没有一个有数据 |
| 从 A 到 B（假范围） | "从数据采集到部署上线"通常什么也没说 |

改法：拆成陈述句，或给每一项配数据。三连形容词改成一句带数字的比较。

## 十、同义词轮换

**同一概念只用一个词。** AI 喜欢在"平台、系统、工具、方案"之间来回换，读者会以为是四个不同的东西。

- 原文：该平台提供数据标注功能。系统支持多人协作。工具还能导出结果。方案适用于中小团队。
- 改写：这个平台提供数据标注功能，支持多人协作，能导出结果，适用于中小团队。

判断方法：把每个名词圈出来，看指代的是不是同一个东西。是就统一。

---

## 十一、主语缺失（中文 AI 的隐形指纹）

禁用/警惕：无需配置、数据告诉我们、市场会奖励、系统会自动处理（谁的系统？）。

改法：补主语。"无需配置"→"用户不用改配置文件"。

---

## 十二、破折号

**不要用破折号（——、--）制造转折。** 中文 AI 文本里破折号密度远高于人类写作。每段最多 1 个，能用逗号、句号、括号就换掉。

---

## 十三、填充词（删了不影响意思的）

禁用：值得注意的是、不可否认、毋庸置疑、总体而言、综上所述、从这个角度来看、总而言之、换句话说、简而言之、一言以蔽之。

改法：直接删。这些词 99% 的情况下删掉后句子更好。

---

## 十四、伪洞察（假装看穿本质）

禁用：真正的问题是、归根结底、本质上、核心在于、说到底。

改法：这些词后面跟的通常是普通结论。删掉前缀，直接说结论。

- 原文：归根结底，模型性能的核心在于数据质量。
- 改写：模型性能主要受数据质量影响。

---

## 十五、开场导览（把目录写成句子）

禁用：让我们深入探讨、本文将带你了解、接下来我们将介绍、首先让我们看看。

改法：删。论文直接进正文。

---

## 十六、格言与伪口语钩子

禁用格言：X 不是工具而是镜子、数据是新的货币、技术的尽头是人文。
禁用伪口语钩子：说实话？、老实讲、重点来了、你敢信、不得不说。

这两类都是"为了显得有人味"而加的，恰恰最像 AI 装人。

---

## 十七、英文同类问题

| 禁用 | 替换 |
|---|---|
| delve into | look at / examine |
| leverage | use |
| robust | strong / stable（有数据就说数据） |
| nuanced | detailed |
| pivotal | important / key（或直接说作用） |
| tapestry / landscape / realm | 删，或说具体领域 |
| underscore / showcase | show |
| seamless / seamlessly | 说清楚哪里不用额外操作 |
| holistic | 说清楚包含哪几部分 |
| cutting-edge | 说清楚新在哪 |
| serves as / stands as | is |
| It's not X, it's Y | 直接陈述 Y |
| em dash 做停顿 | 逗号或句号 |

英文不要为了"高级"换词。用普通词。**不要先译成中文再硬译回英文**——那会产出语法正确但语序诡异的句子。

---

## 十八、不要做的事（过度矫正）

改写方向是"具体、克制"，不是"短、碎、口语"。以下都是错的：

- ❌ 把短句拉长，把"处理"写成"对…进行处理"
- ❌ 为了显得完整而加"的、地、所、会、可以、方面"
- ❌ 为了去 AI 味把学术表达改成大白话（"该结果不显著"→"这结果没啥用"）
- ❌ 堆破折号、碎句、感叹号制造节奏
- ❌ 编金句、反问句、抒情句
- ❌ 加原文没有的数据、日期、来源、因果、评价

**一条干净的句子就少动。不要为了改而改。** 修改率不够时可以再想别的改法，但不能靠口语化凑数。

## 自检：改完逐条过

- [ ] 有没有删掉原文的信息？（对照原文逐句核）
- [ ] 有没有补进原文没有的事实、数字、引用、因果？
- [ ] "具有重要意义 / 通过…实现 / 赋能 / 生态"这类词还剩几个？
- [ ] 同一个概念是不是被换了三个名字？
- [ ] 是不是每句都差不多长？（CV 低于 0.35 就是没改到位）
- [ ] 破折号超过 1 个/段？
- [ ] 该用"是"的地方还在用"体现了 / 标志着"？
- [ ] 有没有出现口语化、网络用语、情绪词？
- [ ] 术语、代码、配置项、API 路径、公式、引用编号是否原样保留？
- [ ] 段落划分是否和原文一致？
